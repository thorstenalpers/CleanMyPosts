### What's Changed

This release rebuilds the window around each platform, makes the delete engine survive an
interface in any language, and fixes the reason sign-in detection never worked.

**Signing in is detected again**

* Fix: The engine talked to a channel that dropped every word. Inside WebView2 the host
  bridge cannot be replaced wholesale, so only its `postMessage` is routed now — which is
  why the app said "not signed in" on X and YouTube while the browser beside it clearly was,
  and why the log stayed empty.
* Sign-in is watched rather than sampled at page load: on both platforms a login completes
  without a document load, so a page that reported "signed out" on the way in never
  corrected itself.

**Deleting**

* Fix: On a page of reposts, X opened the menu of the original author's post — the one with
  "Report post" and no delete entry. The engine now requires a post to be the signed-in
  account's own before it touches its menu, and refuses to act at all when no handle is known.
* Fix: Liked videos on YouTube could not be removed. YouTube moved them to a new generation
  of components, and the menu entry was clicked away by the same gesture that opened it.
* Fix: A single like reported "21 removed". A deletion that leaves the item on the page is
  now a warning instead of a success.
* Fix: Deleting from the wrong page found nothing and said so exactly as an empty account
  would. Every run now opens the page that lists what it is about to delete.
* Fix: YouTube's cookie dialog was never dismissed. It carries a full language picker, which
  put it past the length a banner was allowed to have.

**Any language**

* The interface is available in eleven languages: Arabic, German, English, Spanish, French,
  Hindi, Italian, Japanese, Portuguese, Russian and Chinese.
* Selectors are structural wherever a platform allows it, because every visible label is
  translated. Where wording is the only handle, several languages are matched — and every
  page is now requested in English, which the platforms honour unless the account says
  otherwise.
* When a selector finds nothing, the log can now say which components were on the page and
  quote the markup around them.

**The window**

* Each platform has its own header, sub-navigation and status bar. The sub-navigation stays
  open — running a deletion, finishing one, or switching pages no longer takes the controls
  away mid-task.
* A finished run reports in colour: green when it worked, amber when it found nothing, red
  when it failed, with the number of items removed in the log.
* Themes and the sidebar follow the shared design instead of this app's own styling.
* A start-up screen covers the launch instead of a white flash.

**Settings**

* New: **Reset to defaults** puts every setting back to how a fresh installation starts.
  Signed-in sessions and the log are left alone.
* The "Diagnostic data" switch is gone. It could silence the log entirely, which is the one
  record that explains a failed run.
* Fix: Opening Settings no longer flashes a console window while the app looks for Claude Code.

**Assistant**

* Three modes — ask a question, request an engine repair, or file a bug report — each showing
  exactly what would be sent before anything is sent.
* A report can be handed to GitHub's issue form with the title and body already filled in.
