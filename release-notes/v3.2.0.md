### What's Changed

v3.1.0 gave the updater a face, but you still had to go and find it. This release makes the
app say a new version exists, and puts the most common job on the page it opens on.

**Updating**

* New: The app looks for a new version when it starts and announces it on the overview, with
  the release notes of what changed. Until now a new version was only found by whoever went
  looking for the button on the Info page.
* New: **Look for updates at start-up** in the settings switches that off. On by default; off
  means updates are only found when you ask for them on the Info page.
* Fix: A check that could not reach the release page reported that you were up to date.
  It now says what went wrong instead.

**The overview**

* New: **Delete everything** sits on each platform card you are signed in to. It is the same
  run as the button inside the platform, with the same confirmation naming every list it is
  about to empty — one click from the page the app opens on rather than four.

**While a run is going**

* Fix: The page is now covered for the length of a run. The engine works by clicking the
  platform's own controls, so a click of your own fights it — one on YouTube's navigation
  left the list being emptied, and the run then reported an account that was already clean.

**This installation**

* New: The Info page names the day the build was made alongside its version. A version number
  alone does not distinguish two builds of the same release, which is exactly what a bug
  report needs to tell apart.
