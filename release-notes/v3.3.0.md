### What's Changed

v3.2.0 said the page was covered while a run was going. On X it was not, and every button on
it still worked. That is the main thing this release fixes. The window also stopped being
something the app assumes is wide.

**While a run is going**

* Fix: The platform page is now actually held for the length of a run. The cover was a single
  element in a page X owns and re-renders whenever it likes, so it lasted only as long as X
  left it alone — and once it was gone, a click of your own could navigate away from the list
  being emptied. The run then reported an account that was already clean.
* Fix: The keyboard and the mouse wheel are held too. Neither was ever covered: Tab and Enter
  reached whatever the page had focused, and scrolling fought the run, which scrolls the list
  itself to load more of it.
* Fix: The seconds between opening a list and starting on it are covered as well. The stop
  button was already up and the counter already running, but the page underneath was still
  taking clicks.

Stopping the run gives the page back, as before. Nothing about how a deletion works changed —
the app still clicks the platform's own controls, and it still reaches through the block.

**A smaller window**

* New: The sidebar folds to its icons when the window gets too narrow to carry it, and the
  action column steps aside on a narrower one still, so the platform keeps a page worth
  reading instead of a strip. Both come back as you had them when there is room again, and
  the sidebar toggle keeps working meanwhile — the window folds it, it does not hold it shut.
* New: While a platform is up without its actions, the header carries the way back to them.

**Settings**

* Change: The colour is picked from a dropdown. Seven names in a row wrapped across the width
  of the card; the language setting directly below already showed what that should look like.
