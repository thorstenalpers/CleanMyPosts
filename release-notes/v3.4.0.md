### What's Changed

The assistant stops explaining the engine and starts writing for it. Ask it to empty a list
the app does not handle, and it answers with an action plan you can check before it touches
anything, run once, and keep as a button of your own.

**The assistant writes actions**

- New: **AI Repair** answers with a plan instead of prose. Not code — a short list of steps
  over a fixed vocabulary of clicks, waits, scrolls, navigation and typing, checked against a
  schema before anything runs. A wrong answer can only ask for things the delete engine could already
  do, and only on the platform's own pages; nothing a model wrote is ever run as code inside
  your signed-in session.
- New: **Check first** counts what the plan would find and touches none of it. A selector that
  names the wrong thing is worth finding out about before it has clicked a hundred times.
- New: **Run once** tries the plan on the page in front of you, through the same stop button
  and the same pauses as any built-in action. The plan says how one item goes away; how often,
  how fast and when to stop stay with the app.
- New: A plan does not have to be a deletion. It can open a page, click something away or fill
  a field — YouTube's subscriptions, a cookie banner, a search box — and run once instead of
  emptying a list. Typing is capped short and is the one step that can put something on a page
  rather than take it off; the assistant is told not to use it to write posts or messages.
- New: **Keep as action** gives a plan a name and keeps it. A deletion lands in that platform's
  list, where the confirmation and the stop button are, and stays out of **Delete everything**
  on purpose — it is yours, and it goes stale on its own schedule. Anything else lands in the
  sidebar as an entry of its own.
- New: **Settings → Saved actions** lists every plan you kept with the day you kept it, and
  lets you drop one or all of them. The day is the useful part: a plan is a selector, and the
  platform moves.

**Where the assistant lives**

- New: A sparkles icon in the header opens the assistant as a column beside the platform, so
  the page you are asking about stays on screen while you ask. It keeps the conversation, so
  a follow-up question knows what was just said.
- New: The source, how hard it should think, and the model can be picked there rather than
  only in the settings.

**What a request carries**

- Change: Asking for a plan now sends a skeleton of the open page — tag names, test ids and
  the words on buttons. Every post, handle, address and link is stripped out **in the browser**
  before it goes anywhere, and the preview shows you exactly what would be sent. A selector
  cannot be written against a page nobody has seen; everything that is not needed for one is
  left behind. Questions and bug reports still carry only the log.

**Your language, not English**

- Change: The app no longer appends `lang=en` to every platform page it opens. It mostly did
  not work — both platforms answer in your account's language whatever the address asks — and
  where it did work, it showed you your own account in a language you had not chosen. The
  engine now knows the words it looks for in every language the app offers, so deleting works
  on a German, French, Japanese or Arabic account without the detour.

**Fixes**

- Fix: **Continue in Claude** opened a terminal that immediately said the program was not
  recognised. The command was quoted in a way `cmd.exe` does not read.
- Fix: An engine script that was not valid JavaScript silently took the whole run with it —
  no deletions, no message, and nothing to stop. A broken script now costs nothing but itself.
- Fix: Asking the page how many items match no longer waits forever when the page is busy
  navigating.
- Fix: In Arabic the sidebar disappeared on X and YouTube. The app mirrors itself for a
  right-to-left language, which moves its columns to the other edge — but the platform page is
  placed by the window itself, which could not see that and went on covering the side the menu
  had just moved to. Everywhere else it was fine, because everywhere else the platform is
  hidden.
