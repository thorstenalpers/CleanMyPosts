### What's Changed

Liked videos were being deleted on the wrong page. Everything else here follows from finding
that out — and from the browser extension, built from this same engine, that found it.

**Liked videos move to My Activity**

- Fix: Removing a liked video now happens on Google My Activity, where it is one button beside
  the row, instead of on the Liked videos playlist, where it meant opening a ⋮ menu and hitting
  an entry that three different YouTube renderers each place somewhere else. Menus that flashed
  open and shut, entries that took the click and did nothing, rows that stayed on screen after
  being removed: all of it was that page, and none of it is left.
- Change: **Disliked videos go too.** They are listed there alongside the liked ones, which the
  playlist never showed at all. There is no way to have one without the other on that page.
- Fix: My Activity's own selectors no longer hang on `jscontroller` and `jsname` values.
  Those are Closure output and change with a Google deployment, which is why deleting comments
  would stop working on a Tuesday with nothing in the log to explain it.

**Runs stop waiting for things that are not coming**

- Fix: Deleting an item spent four seconds waiting for a confirmation sheet whether or not one
  ever opened — and on My Activity a liked video goes on the first click. A row that has
  already gone is now the first thing checked.
- Fix: An emptied list took ten seconds to be declared empty: three scroll timeouts of five
  seconds each, twice over. The search for another row is capped at one second in total since
  the last one was found, and the page's own "no activity" notice ends it sooner still.
- Change: The wait after a page loads drops from three seconds to one.

**A run finishes what it started**

- New: An action that deleted anything re-runs itself on a freshly loaded page, until a pass
  deletes nothing. Both platforms leave rows on screen that they have already removed — a pass
  that deleted something is not evidence the list is empty, and only a pass that deleted
  nothing is.

**Timing you can change**

- New: `waits.stepMs`, `waits.searchMs` and `waits.maxFailures` join the patchable engine
  config, so a slow connection or a very large list is something you can settle from
  **Settings → Engine script** rather than wait out. The selectors that only the old playlist
  page needed are gone from it.

**Elsewhere**

- Change: The pointer that follows the automation is a broom, in black and white, instead of a
  red reticle. It no longer rebuilds part of itself on every click either — that put two
  changes into the page inside the window where a menu was supposed to stay open.
- Fix: The standalone script for liked videos points at My Activity like the app does. Download
  it again if you kept a copy.
- New: A Chrome and Firefox extension, built from this same engine and released on its own
  version line. It is not in either store yet; see `extension/README.md` if you want to run it
  from a build.
